# How to Write a Poem Here

Type the poem the way you want it printed.
Each line you type stays a line,
and a blank line starts a new stanza.

Nothing is stretched to fill the width,
so short lines stay short —
the white space is part of the poem.

Give each poem a title with a `#`,
and put each one in its own file
in `content/`, or one after another
with `{break-before=page}` after the title.
